# Mutual Fund Analytics

## Project Overview

This project analyzes mutual fund NAV data to understand fund performance, returns, volatility, risk, and other investment metrics.

## Objectives

- Collect mutual fund NAV data
- Clean and validate the data
- Store data using SQLite
- Perform exploratory data analysis
- Calculate performance and risk metrics
- Build an interactive Power BI dashboard

## Data Sources

- AMFI mutual fund data
- MFAPI NAV API

## Mutual Funds Analyzed

- HDFC Top 100 Direct
- SBI Bluechip
- ICICI Bluechip
- Nippon Large Cap
- Axis Bluechip
- Kotak Bluechip

## Technologies Used

- SQL
